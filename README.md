# MuscleAtlas — атлас упражнений и мышц

Интерактивный сайт про тренировки: нажимаете на мышцу — видите все упражнения, которые её нагружают, и насколько сильно; собираете свою тренировку — и получаете оценку с подсказками, как её улучшить.

Работает полностью в браузере, без сервера и сборки — подходит для GitHub Pages как есть.

## Что умеет

- **Карта мышц (спереди и сзади)** — 30 мышц и их частей: верх / середина / низ груди, три пучка дельт, головки трицепса, верх / середина / низ трапеции и т. д. Наведение показывает название, клик открывает страницу мышцы.
- **Страница мышцы** — функция, как её нагрузить и все упражнения, отсортированные по нагрузке именно на эту часть (например, «Низ груди» → брусья, жим головой вниз, кроссовер сверху вниз…). Фильтры по силе нагрузки и оборудованию.
- **154 упражнения** с тепловой картой: чем больше нагрузка — тем краснее, чем меньше — тем светлее. Для каждого — проценты по мышцам (основные / вторичные / стабилизаторы).
- **Техника выполнения** — фото реального выполнения: два кадра (начало и конец движения) плавно сменяют друг друга, как в гифке; нажатие ставит на паузу и листает кадры. Рядом переключатель «Схема» — анимированный манекен, который подсвечивает работающие мышцы и показывает фазу «вдох / выдох». Плюс пошаговая инструкция, дыхание, частые ошибки, советы и ссылка на видео.
- **Избранное** — звёздочка на любой карточке; из избранного можно в один клик собрать тренировку.
- **Конструктор тренировок** — выбираете группы мышц (или готовый набор: Push, Pull, Ноги, Всё тело…), уровень, цель и своё оборудование, добавляете упражнения, подходы и повторения, меняете порядок перетаскиванием.
- **Оценка тренировки 0–100** по шести критериям:
  - *Покрытие* — все ли части выбранных мышц получили достаточно работы (особенно самая отстающая);
  - *Объём* — общее число подходов и отсутствие «мусорного» объёма;
  - *Баланс* — равномерность нагрузки между частями;
  - *Структура* — базовые упражнения в начале, разумное число упражнений, повторения под цель;
  - *Фокус* — какая доля работы приходится на выбранные мышцы;
  - *Разнообразие* — нет ли дублирующих друг друга упражнений.
  
  Плюс конкретные рекомендации с кнопками «добавить» (например: «Низ груди — недобор: 2,6 из ~5 эффективных подходов» → «Кроссовер сверху вниз +17»), тепловая карта всей тренировки и объём по каждой части мышц.
- **Готовые программы** — 23 тренировки (зал, дом с гантелями, свой вес) и 6 недельных сплитов (Push / Pull / Legs, верх / низ, 5×5, для новичка…). Любую можно посмотреть по составу, добавить себе в один тап и дальше менять в конструкторе.
- **«Собрать за меня»** — алгоритм сам подбирает оптимальную тренировку под выбранные группы и доступное оборудование; кнопка с кубиком даёт другой вариант.
- **Поделиться** — ссылка, в которой закодирована тренировка; получатель может сохранить её себе. Экспорт и импорт всех данных в JSON-файл.
- **Телефон** — вёрстка рассчитана на большие экраны вроде iPhone 15 Pro Max: нижняя панель вкладок, кнопка «назад», окна выезжают снизу, учитываются вырез и полоска «домой». Сайт можно добавить на экран «Домой» (Поделиться → На экран «Домой») — он откроется как приложение, без адресной строки.
- Данные (избранное, тренировки, настройки) хранятся в `localStorage` браузера.

## Запуск локально

Сайт использует ES-модули, поэтому открывать `index.html` двойным кликом нельзя — нужен любой локальный сервер:

```bash
cd muscle-atlas
python3 -m http.server 8000
```

и откройте <http://localhost:8000>.

## Публикация на GitHub Pages

1. Создайте на GitHub новый репозиторий (например, `muscle-atlas`) и загрузите в него содержимое этой папки:

   ```bash
   cd muscle-atlas
   git init
   git add .
   git commit -m "MuscleAtlas"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/muscle-atlas.git
   git push -u origin main
   ```

2. В репозитории откройте **Settings → Pages**, в разделе *Build and deployment* выберите **Deploy from a branch**, ветку **main** и папку **/ (root)**, нажмите **Save**.
3. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/muscle-atlas/`.

С GitHub CLI всё то же самое делается так:

```bash
gh repo create muscle-atlas --public --source=. --push
gh api -X POST "repos/{owner}/{repo}/pages" -f "source[branch]=main" -f "source[path]=/"
```

Маршруты устроены через `#` в адресе (`#/exercise/bench-press`), поэтому прямые ссылки на любые страницы работают на GitHub Pages без дополнительной настройки.

## Структура

```
index.html            — каркас страницы
css/style.css         — стили (тёмная тема в духе Liquid Glass)
js/main.js            — маршруты и запуск
js/router.js          — hash-роутер
js/store.js           — избранное, тренировки, настройки (localStorage)
js/ui.js              — иконки, карточки, модальные окна, подсказки
js/scoring.js         — оценка тренировки, рекомендации, автосборка
js/body/              — анатомическая SVG-карта тела и тепловая подсветка
js/anim/              — проигрыватель техники (фото и схема), движок манекена и шаблоны движений
js/data/muscles.js    — мышцы, группы, готовые наборы, уровни и цели
js/data/ex/*.js       — упражнения по группам
js/data/photos.js     — у каких упражнений есть фото техники
js/data/programs.js   — готовые тренировки и недельные сплиты
assets/ex/            — фото техники: <id>-a.webp и <id>-b.webp
manifest.webmanifest  — установка на экран «Домой»
js/views/             — страницы сайта
```

## Как добавить упражнение

Добавьте объект в подходящий файл `js/data/ex/*.js`:

```js
{
  id: 'my-exercise',                 // уникальный id (будет в адресе)
  name: 'Название',
  en: 'English name',
  alt: 'синонимы для поиска',
  eq: ['dumbbell', 'bench'],         // всё нужное оборудование (см. js/data/equipment.js)
  type: 'compound',                  // compound — базовое, isolation — изолирующее
  level: 1,                          // 1 новичок, 2 средний, 3 продвинутый
  anim: ['press-lying', { tool: 'dumbbell', incline: 30 }], // шаблон схемы из js/anim/motions.js (можно не указывать, если есть фото)
  m: { chest_upper: 100, delt_front: 70, triceps_lat: 45 }, // нагрузка, % от основной мышцы
  reps: '8–12',
  steps: ['Шаг 1…', 'Шаг 2…'],
  mistakes: ['Ошибка…'],
  tips: ['Совет…'],
}
```

Список id мышц — в `js/data/muscles.js`.

Чтобы у упражнения появилось фото техники, положите два кадра (начало и конец движения, WebP, около 800 px по ширине) в `assets/ex/` под именами `<id>-a.webp` и `<id>-b.webp` и добавьте строку `'<id>': 1.5` в `js/data/photos.js` (число — отношение ширины кадра к высоте). Если фото нет, показывается только схема.

Готовая тренировка добавляется в `js/data/programs.js`: название, описание, место (`gym` / `home` / `bw`), уровень, цель, группы мышц и список `[id упражнения, подходы, повторения]`.

## Важно

Проценты нагрузки — ориентировочные: они основаны на данных ЭМГ-исследований и биомеханике движений и показывают относительный вклад мышц, а не точные значения. При травмах и болях проконсультируйтесь со специалистом.
